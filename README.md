# FrameForge Studio — Deliverable 3 Package

## Quick Setup Instructions for VS Code & XAMPP
1. **Clone or Extract** this folder into your XAMPP web root directory (e.g., `C:/xampp/htdocs/frameforge/`).
2. **Open in VS Code**: Open VS Code and select `File > Open Folder...`, then choose the `frameforge_project` folder.
3. **Import Database**:
   - Start **Apache** and **MySQL** in XAMPP Control Panel.
   - Open phpMyAdmin (`http://localhost/phpmyadmin`).
   - Import the `sql/frameforge_db.sql` file to create all 12 normalized tables and seed data.
4. **Run Application**:
   - Open your browser and navigate to: `http://localhost/frameforge/`
